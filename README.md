## Project Status

Completed coursework/lab project prepared as a public portfolio repository.

## Features

- Native Android project structure
- Local persistence practice with SQL concepts
- Gradle-based build setup
- Simple lab-oriented mobile UI flow

## Tech Stack

Android, Kotlin, SQLite, Gradle

## Local Setup

Open the project in Android Studio and sync Gradle. `local.properties` is intentionally not committed.

## Repository Notes

- Generated Gradle/build folders and local SDK paths are excluded.
- No APK binaries are committed.
