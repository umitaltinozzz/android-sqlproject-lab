An Android project focused on local database operations and basic CRUD-style mobile application structure. It was built to practice how a native Android app can store, retrieve, and display data using a local SQL layer.

## What It Does

- Demonstrates local data persistence in an Android application
- Uses a simple multi-screen structure for database-related actions
- Includes Android resources, layouts, activities, and Gradle configuration
- Shows a small but complete mobile project layout suitable for Android Studio

## Tech Stack

- Android
- Kotlin / Java project structure
- SQLite concepts
- Gradle

## Running Locally

1. Open the project folder in Android Studio.
2. Let Android Studio sync Gradle.
3. Add or regenerate `local.properties` through Android Studio.
4. Run the app on an emulator or Android device.

## Repository Notes

Generated Gradle folders, local SDK paths, and APK outputs are excluded. The repository keeps the source code and project configuration needed to inspect and rebuild the project.
